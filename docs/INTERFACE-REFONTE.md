# Refonte de l’interface – Pressing Manager

- Navigation latérale plus sobre, avec un espace Préférences et une barre de défilement affinée.
- Ajout d’un écran Paramètres : choix Français / English, thème clair / sombre mémorisé localement et déconnexion avec confirmation.
- Présentation des différents modules dans Paramètres pour aider les utilisateurs à comprendre la navigation.
- Libellés du tableau de bord principal localisés en français et en anglais.
- Les modules Paiements & caisse et Statistiques restent deux espaces fonctionnels distincts : le premier gère les opérations de caisse, le second les rapports et indicateurs.

## Vérification

Le projet cible `net10.0-windows` avec WPF. Le contrôle de compilation doit être effectué sur Windows avec le SDK .NET 10 installé. L’environnement de préparation de cette archive ne dispose pas de `dotnet`, donc aucune compilation Windows n’a pu être exécutée ici.
